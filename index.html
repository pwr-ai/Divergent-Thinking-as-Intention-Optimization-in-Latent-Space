Beyond Discrete Search: Divergent Thinking as Intention Optimization in Latent Space

We recast LLM-based coding as optimization over a continuous space of intentions — natural-language solution strategies. A Tabu Search explores this space with feedback, steering a coding agent toward correct patches without touching model weights.

The idea

Search where the strategies live, not where the tokens do.

Prompt engineering and agent scaffolds enumerate a discrete set of contexts. We instead treat a solution strategy as a point in a continuous, 4096-dimensional intention space — and optimize over it. Because the geometry is continuous, classical search machinery (neighborhoods, tabu lists, kicks) becomes applicable to natural-language reasoning, letting a small open agent explore strategies it would never have written on its own.

How it works

Two inference-time phases. The agent stays a black box.

Nothing about the coding model is retrained. We wrap it in a search loop that manipulates only the intention it is conditioned on.

Phase 1 — Bootstrap

Reverse-engineer anchor intentions

The agent runs 3× with no guidance. From its reasoning traces we extract the high-level strategies it implicitly used, then embed them as anchor points in the latent space Z (ℝ4096).

3 unguided runstrace → embedding
Phase 2 — Tabu Search

Explore, condition, score, repeat

A neighborhood operator proposes candidate vectors near the current best. Each is decoded into an intention (via CSC / xRAG), the agent is conditioned on it, and the SWE-bench score feeds back. A tabu list blocks cycling and forces exploration.
