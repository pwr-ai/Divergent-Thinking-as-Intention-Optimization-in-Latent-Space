Beyond Discrete Search: Divergent Thinking as Intention Optimization in Latent Space

We recast LLM-based coding as continuous optimization over intentions — natural-language solution strategies. A Tabu Search explores this space with feedback, steering a coding agent toward correct patches without touching model weights.

The idea

Search a continuous signal, not discrete prompts.

Prompt engineering and agent scaffolds pick from a discrete set of contexts. We instead introduce a continuous, 4096-dimensional conditioning signal — not arbitrary noise, but a variable whose values carry real meaning to the model — and search over it; the signal shapes which high-level strategy the frozen agent generates next. Because that space is continuous, classical search machinery becomes applicable to natural-language reasoning.

How it works

Turn “get the model to solve it” into a search problem.

An agent often can solve a task — it just needs the right framing, such as a well-placed hint in a human's prompt. So we make the framing itself the search variable: a continuous conditioning signal z ∈ ℝd. This z is not a random variable — its values carry meaning the LLM can act on. Conditioned on z, the agent first samples a high-level intention (a natural-language strategy), then writes code conditioned on that intention. For z to carry that meaning, we map it through the xRAG projector into the LLM's embedding space.

Phase 1 — Bootstrap

Seed the space with anchors

Run the agent a few times unguided. From its reasoning traces, extract the strategies it implicitly used and embed them (φ) as anchor vectors in the latent space — a starting neighborhood for the search.

Phase 2 — Search & evaluation

Explore, condition, score, repeat

Tabu Search proposes neighbor vectors of the current best; each is decoded to an intention (δ, via xRAG), the agent writes a patch, and the test score feeds back. A tabu list blocks revisits and forces new strategies.
